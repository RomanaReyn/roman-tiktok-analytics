Privacy Policy

Last updated: November 24, 2026

1. Introduction

Roman TikTok Analytics is a personal, non-commercial application currently under development. This policy describes its intended data processing practices.

2. Information Collected

Once the TikTok integration is enabled, the application may collect the following authorized information:

  • Basic account information and profile identifiers.
  • Username and public profile information.
  • Follower and following counts.
  • Total account likes and video counts.
  • Public video information and publication dates.
  • Video views, likes, comment counts and shares.
  • Authentication tokens required for API access.

3. How Information Is Used

Information is used exclusively for personal content performance analysis, historical comparisons and account growth monitoring.

4. Data Storage and Security

The application is designed to store analytics data in a local SQLite database. Authentication credentials and tokens must be stored separately from public source code and must not be published.

5. Data Sharing

The application does not intend to sell, rent or disclose collected account data to third parties, except when required by applicable law.

6. Data Retention and Deletion

Data will be retained only as necessary for the stated analytics purposes and subject to TikTok's applicable developer requirements.

Account owners may request access, correction or deletion of their stored data by contacting the project operator.

7. Revoking Access

Account owners may revoke application access through their TikTok account settings. Upon revocation, the application must stop collecting account data and handle previously stored data according to applicable requirements.

8. Cookies and Website Hosting

This informational website does not implement its own tracking cookies or advertising scripts. It is hosted through GitHub Pages, which may process technical information under its own privacy policies.

9. Third-Party Services

The application uses TikTok's official API. TikTok's own privacy policies apply to its services.

10. Changes to This Policy

This policy may be updated as the application evolves. The latest version will be published on this website.
